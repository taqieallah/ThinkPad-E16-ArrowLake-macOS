# ملخص بالعربي

هاكنتوش على **ThinkPad E16** بمعالج **Core Ultra 7 255H (Arrow Lake)** وكارت **Intel Arc 140T (`8086:7D51`)**، على **macOS 26 Tahoe**.

## الحالة النهارده
- **تسريع كارت الشاشة شغال:** WindowServer بيرسم على الكارت عن طريق تعريف XeGfx (‏i915 بتاع لينكس شغال على macOS) ومعاه تعديلاتنا.
- **الشاشة شغالة على 60.01 هرتز** (اتقاست فعلياً).
- **العرض المباشر من غير نسخ (zero-copy flip):** الفريمات بتتعرض من مكانها في الذاكرة، 0 فشل.
- **K9b:** WindowServer مبقاش يستنى الكارت كل فريم، والتعريف هو اللي بيرتّب في الخلفية. 0 فريمات اتعرضت ناقصة.
- **السلاسة:** اتحسنت شوية، بس لسه مش 60 فريم. الخطوة الجاية قياس WindowServer بـ `sample`.
- **الألوان والوايفاي** اتصلحوا بعد تحديث macOS. **التاتش باد والبطارية والصوت** شغالين.
- **مش شغال لسه:** السليب والشاشات الخارجية، لأن التعريف لسه مش ماسك الـ display engine بنفسه.

## تجربة ArcMTL
تعريف تاني بيستبدل i915 بتعريف kernel صغير اسمه ArcXe:
- **اللي نجح:** الكارت نفّذ أوامر ورسم 3D.
- **اللي فشل:** رفع الـ textures بيهنّج الكارت، فسطح المكتب طلع أسود ومفيش غير الماوس. صاحب المشروع لقى نفس المشكلة وبيصلحها.
- **اللي صلحناه:** نمط الـ nested batch.
- **الوضع دلوقتي:** التعريف ده متطفّي ومبيشتغلش غير بـ boot-args، فاحنا رجعنا لتعريفنا.
